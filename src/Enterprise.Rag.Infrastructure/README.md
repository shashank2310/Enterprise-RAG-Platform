# Infrastructure adapters

This project contains the Ollama and Azure OpenAI model adapters, PostgreSQL persistence and cosine retriever, an Azure AI Search retrieval adapter, document extraction, and optional Azure AI Document Intelligence OCR. The Ollama/PostgreSQL path is the runnable local route: vectors are stored as JSONB, candidates are restricted to the current tenant, and cosine similarity is calculated in application memory. The local retriever does not enforce document-level group ACLs and is intended only for small development corpora.

The local upload path stores extracted chunks and embeddings, not the original file. Azure AI Search currently has a query adapter but no index writer/upsert/delete lifecycle; Azure Blob Storage and Service Bus clients can be registered but are not used by ingestion. Selecting the Azure OpenAI provider also needs complete orchestration and ingestion-service wiring before it can serve as an end-to-end cloud path. Production work includes durable source-file storage, malware/signature validation, background ingestion, scalable indexing, ACL enforcement, and evaluation/observability. Keep credentials out of configuration and browser builds; use managed identity and a secrets manager in cloud deployments.
