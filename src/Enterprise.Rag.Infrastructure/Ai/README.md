# Azure AI adapters

The Semantic Kernel connector uses Azure Identity `DefaultAzureCredential`; assign its workload identity only the required Azure OpenAI data-plane role. Configure the endpoint and named chat/embedding deployments (`AzureOpenAI:Endpoint`, `AzureOpenAI:ChatDeployment`, and `AzureOpenAI:EmbeddingDeployment`) so model choice, capacity, and vector dimensions are explicit. The grounded generator accepts only citation IDs present in retrieved context and currently returns confidence `0` because no calibrated scorer is connected.

`AzureAiSearchHybridRetriever` is a query adapter: it creates a query embedding, submits semantic text plus vector search, and constructs tenant/group filters. It requires a matching provisioned index and fields such as `tenantId`, `groupIds`, `isTenantWide`, and `contentVector`. There is no Azure AI Search chunk writer, upsert/delete lifecycle, or complete Azure ingestion/orchestration wiring yet; do not treat these adapters as a deployed end-to-end service.
